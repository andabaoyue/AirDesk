# 常见问题排查指南 (Troubleshooting)

## 1. 局域网 / 手机热点扫不到电脑或连接超时

**原因 1：Windows 防火墙拦截「公用网络」**
- 手机开启个人热点后，Windows 通常会把该 Wi-Fi 网络识别为「公用网络（Public Network）」。
- **解决**：在 AirDesk 桌面端点击「一键放行端口 47820」（授予管理员 UAC 一次即可写入入站规则），或手动在 Windows Defender 防火墙放行 TCP 与 UDP `47820`（覆盖公用/专用网络）。

**原因 2：手机或电脑开启了代理工具（TUN 模式）**
- 代理工具的虚拟网段（如 `198.18.0.0/15` / `172.19.x.x`）会干扰局域网候选探测。
- AirDesk 已默认拦截已知代理 TUN 网卡，但如果代理开启了全局接管且与热点网关冲突，建议将局域网私有网段（`192.168.0.0/16`、`172.20.10.0/24` 等）设为直连绕过。

**原因 3：企业 Wi-Fi 开启了 AP 隔离（Client Isolation）**
- 公共或公司 Wi-Fi 往往禁止终端间直连。可改用**手机个人热点**，或连接 **USB 数据线 + 开启 USB 网络共享 / 点击桌面端「USB 直连」**。

---

## 2. 弹窗（如任务管理器 / 管理员终端 / UAC 窗口）无法点击

- **原因**：Windows 的 UIPI 安全机制禁止普通用户权限进程向高完整性（管理员）进程或 Secure Desktop 注入输入。
- **解决**：
  1. 在 AirDesk 桌面端切换到「设备与快捷键」页，点击 **「安装后台提权服务（SYSTEM）」**（仅首次需管理员授权，之后开机自启并在独立 Session 下以 `NT AUTHORITY\SYSTEM` 运行，通过带随机密钥校验的受限命名管道接管输入，并支持发送 `Ctrl+Alt+Del` SAS）。
  2. 注意：**在 UAC 弹窗或系统锁屏期间，受 Windows 系统桌面隔离限制，Electron `desktopCapturer` 屏幕采集可能会短暂暂停或黑屏**，这是系统底层限制，待切回默认桌面后自动恢复。

## 3. 画面延迟高、掉帧或解码显示软编/软解

请在 Android 端悬浮抽屉打开 **「调试 HUD」** 观察两行遥测：

1. **查看 PC 端是「硬编」还是「软编 (OpenH264)」**：
   - 若核显/旧驱动被 Chromium 拦截或处于软编，可在桌面端先保持默认 `30 fps` 与 `自动硬编探测 (auto)`；
   - 若电脑为独显且确认支持 HEVC 硬编、手机端支持 HEVC 硬解，可在两端偏好中尝试切换 `H.265 / HEVC`。
2. **查看 Android 端 `缓冲` 与 `解码` 耗时**：
   - 正常硬解单帧通常 `< 12ms`。若 `缓冲` 持续偏高，优先检查是否误走了公网中继或 Wi-Fi 信号弱，可切换为「流畅 900p」或使用 5GHz 热点 / USB 有线链路。
3. **Android 端 10 分钟后后台断连**：
   - 请在手机系统设置中对 AirDesk 关闭省电限制（允许后台高耗电 / 自启动，或使用应用内「忽略电池优化」引导）。

---

## 4. 无显示器电脑黑屏（提示无法采集）

AirDesk **不采用虚拟显示器驱动（VDD）**，依赖系统当前活跃的物理或显卡输出显示器。如用于无头（Headless）主机，建议插一枚几元钱的 HDMI/DP 显卡欺骗器（Dummy Plug）。
